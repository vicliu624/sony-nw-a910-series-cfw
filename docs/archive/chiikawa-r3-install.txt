Sony NW-A918 — English 1.03 / Chiikawa B1 R3

This experimental build combines complete English R2 wording with the approved
nine Chiikawa characters and B1 meadow icon textures. It has not been tested on
the device yet. Do not treat an offline preview as a captured device screen.

What is included:
- English R2 wording: 648 nonempty entries, no missing entries versus Japanese.
- 81 replacement numbered animation frames and 14 static icon textures.
- Meadow background composited into the nine icon tiles.
- Original black regions outside the icon grid remain. Full-screen wallpaper
  and the light status/text panels shown in the design preview are NOT included.

Install directory:
C:\Users\VicLi\Documents\Projects\sony-nw-a918\work\install-english-chiikawa-b1-r3

Run FWUpdater.exe in this directory. Keep NW_A91X.UPG, NW-A91X.ini and the DLLs
beside it. NW_A91X.UPG here is the Chiikawa R3 candidate, not the stock image.
Use the complete directory, or extract the supplied ZIP before running it.

Connect the NW-A918 using a data-capable USB cable with sufficient battery.
Handle UAC manually. Check the detected model and follow the Sony updater.
Keep USB connected throughout updating and follow completion instructions.
This package targets NW-A918; no A916/A919 hardware validation is claimed.

The firmware version is still 1.03. Reinstalling over an existing 1.03 firmware
may be rejected by the original updater. No version spoof or forced-upgrade
bypass is included. If rejected, stop and report the exact message.
