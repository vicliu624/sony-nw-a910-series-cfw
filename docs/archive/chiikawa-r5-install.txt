Sony NW-A918 — English 1.03 / Chiikawa Dark R5 Footer

- Main icon grid: x=0..239, y=28..243, nine 80x72 numbered textures.
- Home item-name background: x=0..239, y=244..287, 240x44 DTX.
- Playback status background: x=0..239, y=288..319, 240x32 DTX.

The background is darkened smoothly starting at y=220, reaching 20% brightness
at y=244. Every bottom pixel meets at least 7:1 computed contrast with white
after RGB565 conversion. This is not a physical LCD measurement.

The same master background is cropped for all regions, not redrawn separately.
Original DTX sizes, headers and DPK indices are retained. The Home top header
is unchanged. Native item labels, artist, playback and battery indicators are
still rendered by Sony's original application.

will also use this dark theme strip. Their foreground text/icons are unchanged.

Resources changed: 81 numbered icon frames, 14 static icon textures, 2 bottom
strips. Complete English R2 wording is preserved, 648 nonempty records.
