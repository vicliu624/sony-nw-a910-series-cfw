# A918 English / Chiikawa R12 Color Menu ALPHA1

在 R11 性能版基础上补齐彩色 iD 菜单、重新开始、备份恢复和短按输入。
这是本地检查通过、尚未在 A918 实机验证的新候选。R10/R11 升级包完整保留。

## 彩色 iD 操作

左=A，中间播放/暂停=B，右=C。下方向键现在打开英文菜单，不再直接退出：

- CONTINUE：继续游戏。
- SAVE AND EXIT：保存并返回 Games 列表。
- NEW GAME：进入确认页，确认后备份当前存档并回到最初的日期时间设置。
- RESTORE BACKUP：进入确认页，确认后恢复上次重新开始前的备份。

上下选择，中间键确认。危险操作默认选择 CANCEL；下移到 YES - CONFIRM 再确认。
菜单期间停止推进模拟时间，清空待处理的 A/B/C，防止继续游戏后积压按键突然触发。
USB 接入或正常结束仍会尝试保存并返回 Sony。P1 和 Tetris 操作保持原样。

## 真正重新开始

公开 iD ROM 自身包含旧游戏内容，只删除模拟器存档并不能保证得到全新宠物。
因此本包内置一个与原 ROM 绑定的新游戏初始状态：在原游戏里实际执行
A/B/A/B，选择 RESET，再在「ほんとうに？」页选择「はい」并确认，
得到最初的月/日/时间设置页。不是在 ROM 上盲目擦除区域。

初始状态文件 /usr/local/bin/a918-color-id-new.sav：877403 字节。
SHA256 d742d6938b95ab27ab0c62e2d2f1c6539bdfb423e8c4e9e47dcf23b54449c7ea。
它是可移植的小端序列化状态，不包含宿主指针；原始 iD ROM 文件保持不变。

确认 NEW GAME 后先保存当前状态，再将 color-id.sav 重命名成 color-id.bak，
随后加载初始状态并保存。只保留一份“上次重新开始前”的备份；再次确认 NEW GAME
会更新这份备份。恢复不会删除备份。操作失败会保留在菜单并显示失败提示。
写入失败、备份失败、缺少备份和取消路径都进行了本地检查；真实闪存断电行为未验证。

## A/B/C 漏按修复

旧版会在一次输入轮询中连续处理按下、松开，客体尚未运行就清掉按键。
真实 iD ROM 本地复现：快速 B 的画面与不按键一致，按住 B 才进入游戏。
R12 用 64 个事件的有界队列，使按下及松开各至少保持约50毫秒客体时间，
且在模拟计算批次之间投递事件。正常短按 B 现在与按住 B 一样能触发真实游戏。
队列满时清空并释放按键，避免卡住；不承诺无限快速连续输入。

菜单、退出、重开和读档时释放按键并清空队列，不把待处理输入写进存档。
有排队输入时画面显示 PROCESSING INPUT - PLEASE WAIT。
这修复了漏事件路径；模拟器运行慢仍可能导致等待，不能把它当作提速或满帧证明。

## 保留的行为与验证

继承 R11 的 -O2 彩色核心、约24ms目标计算预算、1ms休眠、50ms画面提交间隔。
计算预算在批次结束时检查，不是硬实时截止。128×128，不放大；无声音或联机。
Sony 主程序、内核、驱动、音频、资源、P1 ROM、iD ROM 和启动脚本保持不变。

Host ASan/UBSan：P1、Tetris、彩色存储、菜单暂停/继续/取消、保存失败重试、
缺失/失败备份、重新开始、恢复原画面、退出再进、实际 ROM 短按回归。
ARMv5/OABI + QEMU ARM926：P1/iD、文件存储、新游戏及备份恢复、短按锁存、进程监护。
另有 21 个实际 ARM 工作进程模拟系统调用场景及 22 个原 Sony 内核分派检查。
最终 UPG 用独立 Rockbox 工具解包比较。没有自动刷写。

使用本 release 的 updater/FWUpdater.exe 与同目录 NW_A91X.UPG。
进入 Games 时拔掉 USB 后完整重启；USB 已连接时仍优先进入 Sony。

回退：releases/R11-Color-iD-Perf-ALPHA1/updater/FWUpdater.exe。
旧版能读取相同格式的普通存档，但没有新的菜单和恢复备份按钮。
