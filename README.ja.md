## 概要

ソニー純正の更新パッケージを展開し、画面プログラムとリソースを調べ、中国語・英語の不足する訳を補って再構築しました。ちいかわのテーマとゲームの起動メニューは、画面の変更と自作コードの実行を示す例です。

ここで使った方法は、他の Sony NW シリーズを調べる際にも参考になります。ただし、システム、鍵、ハードウェアは機種によって異なるため、個別の調査が必要です。

純正リソースには英語、日本語、フランス語、ドイツ語、イタリア語、スペイン語、簡体字中国語、繁体字中国語、ロシア語、韓国語、ポルトガル語の11言語があります。本工程では中国語・英語の不足を補訳しました。他の言語にも取り組めるよう、言語IDとリソース構造を文書化しています。

## Rockboxへの謝辞

本工程は、[Rockbox](https://www.rockbox.org/)によるSony UPG形式の研究を利用しています。[upgtools](https://github.com/Rockbox/rockbox/tree/master/utils/nwztools/upgtools)を使い、このファームウェアのDES等価鍵の探索、展開・再構築、変更後パッケージの独立した検証を行いました。

言語・リソースの変更と自作プログラムはソニー純正システム上で動作します。RockboxのOSを導入するプロジェクトではありません。ツールのソースと由来は `third_party/rockbox-upgtools/` に保存しています。

## 対応状況

ソニー A910 用の1.03を基にしています。実機テストの記録があるのは NW-A918 のみで、NW-A916／NW-A919 は未検証です。初期の言語・テーマ変更は A918 で動作しましたが、英語alpha.3のアプリ一覧とアプリ動作はユーザーがNW-A918で確認しています。中国語版やその他の動作は未検証です。

CIは簡体字中国語（`zh-CN`）と英語（`en`）を別々に生成します。各版は一つの言語を使い、機器内での切替はできません。現在のパッケージにはテーマと起動メニューの例を含みます。ゲームROMは別途用意してください。

## ビルド

依存関係を用意し、プロジェクト直下で順番に実行します。

```sh
python scripts/build_release.py --language zh-CN
python scripts/build_release.py --language en
```

出力先は `dist/<VERSION>/<language>/` です。純正更新ツール、ファームウェア、サンプルプログラム、ソース、検証結果を含みます。ゲームROMや初期化用セーブは含めません。

GitHub Actions は push と PR を検査します。[VERSION](VERSION)と一致する `v<version>` タグ、または手動要求により、ビルド成功後に実験版のプレリリースを作成します。

## ディレクトリ

- `scripts/`：解析・ビルド・検証ツール。
- `translations/`：中国語・英語の翻訳。
- `assets/patches/`：純正ファームウェアに対する変更。
- `games/`：自作プログラムの例。
- `docs/`：技術資料。過去の調査は `docs/archive/`。
- `work/`：一時ファイル。`dist/`：ビルド結果。どちらもGit対象外です。

工程の版は [VERSION](VERSION) で管理し、機器上のソニーのバージョンは1.03のままです。コードと画像の権利については [THIRD_PARTY](THIRD_PARTY.md) を参照してください。
